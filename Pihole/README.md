# PiHole Server
<img width="130" alt="image" src="https://github.com/user-attachments/assets/5cfeac45-eaac-4b3e-931e-643a92ff43e2" />

Pi-hole is a free, open-source network-wide ad blocker and DNS sinkhole.\
Blocks ads, tracking from known 3rd party ad sites.

---

Simply run the [docker-compose.yml]() inside the folder in which you store your persistent data.\
```docker compose up -d```.\
Your PiHole container is now online. Configure any devices DNS settings to point to the PiHole to block ads.\
Web Console: ```http://YOUR_IP```
