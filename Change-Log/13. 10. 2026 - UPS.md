# Installed a Geekworm x1201 UPS HAT alongside a new case.
https://geekworm.com/products/x1201 \
https://geekworm.com/products/x1201-c1

This was bought and installed due to a power outrage which caused severe disk corruption.\
With this UPS HAT the Pi now stays powered on and draws power from the latched batteries even in the events of complete power outrage.\

## Difficulties
### Boot
The bootloader was halting because USB boot on the Raspberry Pi 5 requires a high-current power supply (officially 5V, 5A via USB-C PD).\
My power supply is an official 5V, 5A output. So my PSU output is sufficient.\
This halt happens, because the bootloader expects the initial handshake between a PSU that is directly connected to the Pi.\
Because the Pi now draws power from the UPS hat, the bootloader throws out a default warning. Even though the PSU output is sufficient.

I bypassed this by adding one line to the /boot/firmware/config.txt file:\
```usb_max_current_enable=1```\
Note: This is fine because im using a PSU with sufficient output. But the bootloader will no longer halt even if plugged into a lower output device which should be taken into consideration.
