## Installation Difficulties
### Boot
The bootloader was halting because USB boot on the Raspberry Pi 5 requires a high-current power supply (officially 5V, 5A via USB-C PD).\
My power supply is an official 5V, 5A output. So my power supply output is sufficient.\
This halt happens, because the bootloader expects the initial handshake between a power supply that is directly connected to the Pi.\
Because the power supply is now directly connected to the UPS hat which supplies the Pi with power, the bootloader throws out a default warning. Even though the output is sufficient.

I bypassed this by adding one line to the /boot/firmware/config.txt file:\
```usb_max_current_enable=1```\
Note: This is fine because im using a power supply with sufficient output. But the bootloader will no longer halt even if plugged into a lower output device which should be taken into consideration.
