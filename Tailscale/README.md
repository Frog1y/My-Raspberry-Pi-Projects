# Tailscale

<img width="256" height="256" alt="image" src="https://github.com/user-attachments/assets/3c6d4318-5fdd-4a2f-9544-6654bbc5b43e" />

Tailscale is a Mesh Virtual Private Network (VPN) built on top of the WireGuard protocol.\
It securely connects your servers, computers, and mobile devices directly to one another in an encrypted private network.\
Managed in the tailscale web console.
